# Building AreaShop-OG

```
git clone --recurse-submodules https://git.trueog.net/trueog/AreaShop-OG.git
cd AreaShop-OG
./gradlew build
```

The usable jar is `AreaShop-OG/build/libs/AreaShop-OG-<version>.jar` (the `-original` and `-sources` jars are not the
plugin). More detail in [compiling.md](compiling.md).
